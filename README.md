# Trilhas Papelaria - Simulador de Compras

Nome do Projeto: Simulador de Compras - Desafio 1
Aluno: VANESSA RAYSSA ARAÚJO BRAGA
Trilha: Desenvolvimento Mobile | Programa Trilhas 2026

## Apresentação
Loja fictícia de papelaria que permite simular uma compra.
- Caderno: R$ 20,00
- Caneta: R$ 5,00
- Mochila: R$ 80,00

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript

## Instruções de Execução
1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` diretamente em seu navegador web.
3. Clique no botão "Simular minha compra" e siga os prompts na tela.

- Testes realizados: Teste de inserção de texto no lugar de números, validação de carrinho vazio (quantidades zeradas) e cálculo total.
